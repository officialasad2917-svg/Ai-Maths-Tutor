Rational ya irrational?

Terminating/repeating decimals rational hote hain.
(i) 2.353535

Decimal khatam ho raha hai. Isay fraction mein likh sakte hain: 2353535/1000000.

Rational
(ii) 0.6̅ = 0.666…
SOLUTION
x=0.666…; 10x=6.666…
10x−x=6 → 9x=6 → x=2/3
Rational
(iii) 2.236067…

Non-terminating aur non-repeating decimal (diye gaye form mein); yeh √5 ke qareeb hai.

Irrational
(iv) √7

7 perfect square nahi, is liye √7 exact fraction nahi banta.

Irrational
(v) e

Euler number e ka decimal non-terminating aur non-repeating hai.

Irrational
(vi) π

Pi ka decimal non-terminating aur non-repeating hai.

Irrational
(vii) 5 + √11

Rational 5 ko irrational √11 mein add karne se irrational result milta hai.

Irrational
(viii) √3 + √13

Yeh sum rational nahi ho sakta; dono radicals alag square-free parts rakhte hain.

Irrational
(ix) 15/4

Do integers ka ratio hai aur denominator zero nahi.

Rational
(x) (2−√2)(2+√2)

= 2² − (√2)² = 4−2 = 2

(i) √2 ≈ 1.414

0 se 1 unit lo. 1 par 1 unit ka perpendicular banao. Hypotenuse √(1²+1²)=√2 hai. Is length ko compass se 0 se right side mark karo.

(ii) √2+√3=√3+√2 — Commutative property of addition

(iv) a(b+c)=ab+ac — Distributive property
(v) 16+0=16 — Additive identity property

5

Order / inequality properties

(i) −3<−1 ⇒ 0<2 — dono sides mein 3 add kiya. Addition property of inequality
(ii) If a<b then 1/a>1/b — Reciprocal property of order (positive a,b)
Yeh statement tabhi sahi hai jab a aur b positive hon. General case mein condition zaroori hai.
(iii) If a<b then a+c<b+c — Addition property of inequality
(iv) If ac<bc and c>0 then a<b — positive c se divide karne par sign same rehta hai. Division property for positive number
(v) If ac<bc and c<0 then a>b — negative c se divide karne par sign reverse hota hai. Division property for negative number
(vi) Either a>b or a=b or a<b — Trichotomy property of order
