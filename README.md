# AI Maths Tutor — Premium Design Prototype

Responsive static website built with HTML, CSS, and JavaScript.

### Included
- Dark premium visual theme with purposeful color grading
- Responsive homepage and learning dashboard
- Sample question selector and previous/next navigation
- Formula, calculation, Roman Urdu explanation, final-answer cards
- Method 1, Method 2, and exam-ready views
- Interactive MCQ feedback
- No paid API, backend, or subscription dependency

### Important
The included questions are demo examples, not verified Punjab Board textbook questions. Verify textbook content and solutions before using them as official exercise content. Method 1 and Method 2 must be genuinely distinct where suitable; do not force a second method if it is not mathematically useful.

### Publish with GitHub Pages
Upload `index.html` to the root of your repository. Open Settings → Pages, choose deployment from the `main` branch and `/ (root)` folder, then save. Check current GitHub Pages terms and limits. No paid plan is needed for this static prototype.
